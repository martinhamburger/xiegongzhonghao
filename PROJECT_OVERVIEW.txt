🚀 快速开始
───────────────────────────────────────────────────────────────────────────

安装方法:
1. git clone https://github.com/martinhamburger/xiegongzhonghao.git
2. 打开 chrome://extensions/
3. 启用"开发者模式"
4. 加载 browser-extension 文件夹
5. 点击扩展图标开始使用

详细说明请查看: INSTALL.md 和 QUICKSTART.md

───────────────────────────────────────────────────────────────────────────
