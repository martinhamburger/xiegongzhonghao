# 去AI味写作指南

## 概述

AI生成的内容往往有明显的"机器味"——句式单调、过度衔接、缺乏情绪。本指南帮助你写出更自然、更有个人风格的文章。

---

## 一、常见AI写作特征

### 1.1 过度使用衔接词

**AI特征：**
- 连续使用"首先、其次、再次、最后"
- 过度使用"因此、所以、但是、然而"
- 每个段落都用"另外、此外"开头

**改进方法：**
- 删除不必要的衔接词
- 用句子本身的关系自然表达
- 减少过渡，直接进入主题

**示例：**
```
❌ 首先，我们需要了解什么是AI。其次，AI的应用非常广泛。此外，AI还在不断发展中。
✅ 说到AI，你会想到什么？可能很多人第一反应是ChatGPT。但AI的世界远比这丰富。
```

### 1.2 句式过于工整

**AI特征：**
- 喜欢用"一方面...另一方面..."
- 过度使用排比句
- 喜欢用"既...又..."结构

**改进方法：**
- 打破句式平衡
- 长短句交错
- 用口语化表达代替书面语

**示例：**
```
❌ AI不仅改变了我们的生活方式，也重塑了工作模式，既提高了效率，又带来了新的挑战。
✅ AI到底改变了什么？最直接的，是效率。但仔细想想不止如此——它改变了我们解决问题的方式。
```

### 1.3 正确的废话

**AI特征：**
- "随着时代的发展..."
- "在当今社会..."
- "显而易见的是..."
- "我们需要注意的是..."

**改进方法：**
- 删除这类开场白
- 直接切入主题
- 用具体场景代替泛泛而谈

**示例：**
```
❌ 随着互联网的快速发展，人们获取信息的方式发生了翻天覆地的变化。
✅ 你有没有发现，现在搜一个问题，前面几页全是广告？
```

### 1.4 过度总结

**AI特征：**
- 频繁出现"综上所述"、"总之"、"总而言之"
- 每个小节都要有个总结段
- 结尾一定要"展望未来"

**改进方法：**
- 减少总结性语句
- 用故事/例子收尾
- 留白，让读者自己思考

**示例：**
```
❌ 综上所述，AI技术发展前景广阔，我们应该积极拥抱这一技术变革。
✅ 写到最后，我突然想到一个问题：十年后，我们还会记得"不会用AI"这件事吗？
```

## 二、句式变换技巧

### 2.1 疑问开头

用问题引出话题，比陈述句更有吸引力。

```
❌ 我认为这个观点很有意思。
✅ 这个观点，真的对吗？
```

### 2.2 打破句子平衡

不要总是主谓宾结构，加点倒装、插入语。

```
❌ 这个方法很简单，只需要三步。
✅ 只需要三步——很简单，对吧？
```

### 2.3 用具体代替抽象

把"提高效率"变成"从3小时缩短到20分钟"。

```
❌ AI可以大幅提高工作效率。
✅ 以前写一篇公众号要一下午，现在20分钟搞定。
```

### 2.4 留白与断句

适当断行，用短句制造节奏感。

```
❌ 这个概念看起来很复杂但是只要理解了它的本质就很简单的
✅
这个概念，看起来很复杂。
但只要理解了它的本质——
其实没那么难。
```

## 三、口语化表达示例

### 3.1 语气词

适当加入语气词，增加亲近感。

```
✅ 说白了，就是这么回事
✅ 说句大实话
✅ 你还别说
✅ 讲道理
✅ 私以为
```

### 3.2 反问与设问

增加互动感。

```
✅ 难道不是吗？
✅ 你有没有想过...
✅ 这是不是有点离谱？
```

### 3.3 自嘲与调侃

增加个人风格。

```
✅ 踩过的坑比吃过的盐还多
✅ 作为一个曾经的受害者...
✅ 交过的学费...
```

## 四、套话清单及替换方案

| 常见套话 | 替换方案 |
|---------|---------|
| 随着时代的发展 | 直接说事 |
| 在当今社会 | 直接说事 |
| 显而易见的是 | 删除或直接说 |
| 我们需要认识到 | 删除或直接说 |
| 综上所述 | 用故事/例子收尾 |
| 展望未来 | 留白或提出问题 |
| 不得不承认 | 说实话 |
| 综上所述 | 说白了 |
| 值得注意的是 | 删除或直接说 |

## 五、去AI味检查清单

完成文章后，用这个清单检查：

- [ ] 删除所有"首先、其次、再次、最后"（除非真的是步骤）
- [ ] 删除所有"综上所述"、"总之"
- [ ] 检查是否有连续3个以上相同结构的句子
- [ ] 每个段落是否都有具体例子/场景？
- [ ] 是否有口语化的表达（语气词、反问）？
- [ ] 结尾是否留白而非总结？
- [ ] 是否有一些个人风格（吐槽、自嘲）？

## 六、快速修改技巧

### 技巧1：朗读法

把文章朗读出来，不自然的地方会立刻发现。

### 技巧2：删减法

先删掉所有过渡词、总结句，再看是否通顺。

### 技巧3：替换法

把每个"我们"改成"你"或"我"，增加代入感。

### 技巧4：场景法

每个观点都问自己：能不能用一个具体的例子/故事来说明？
